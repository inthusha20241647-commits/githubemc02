# Git & GitHub Practice

A simple repository created to practice basic Git and GitHub workflows.

## What I Practiced

* 🌿 **Branching** – Created separate branches to work on changes independently.
* 🔀 **Merging** – Combined changes from one branch into another.
* 🔄 **Pull Requests** – Created Pull Requests to propose and review changes before merging.
* 💾 **Commits** – Saved changes with meaningful commit messages.
* 📤 **Push & Pull** – Practiced transferring changes between local Git and GitHub.

## Tools Used

* Git
* GitHub
